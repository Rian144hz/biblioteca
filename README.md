# biblioteca

# Como rodar:

## Clonando o repositório
`git clone https://github.com/Rian144hz/biblioteca`
## Acessando a pasta
`cd biblioteca`
## Compilando os arquivos
`javac *.java`
## Rodando o projeto
`java Main`

Projeto feito com intuito de aprender a linguagem de programação Java.

```
git clone https://github.com/Rian144hz/biblioteca
cd biblioteca
javac *.java
java Main
```
